      DOCUMENTATION

      How BOTPass works

      The main flow follows the same order as the product menu.

      01

      Events

      Browse current events and select Get pass while the event is running and passes are available. Each wallet can record attendance once per event, using BOT for transaction gas.

      02

      Create

      Connect an organizer wallet, enter the event details and dates, then confirm the transaction. The new event starts with passes paused.

      03

      Manage

      Only the wallet that created an event can enable or pause its passes. The controls appear automatically when that organizer wallet is connected.

      04

      My Passes

      Connect a wallet to see its recorded event passes and the time each pass was added.

      05

      Verify

      Anyone can check an event ID and wallet address. BOTPass reads the contract and shows whether a pass exists.
